# 박성준 포트폴리오 GitHub Pages

정적 파일만으로 동작하는 포트폴리오 페이지입니다.

## 파일 구성

- `index.html`: PDF 목차를 반영한 8개 챕터 페이지 구조와 문구
- `styles.css`: 반응형 디자인
- `script.js`: 이미지/동영상 목업 카드 18개와 나중에 넣을 미디어 경로

## 이미지·동영상 넣는 방법

1. `script.js`를 엽니다.
2. `mediaItems` 배열에서 원하는 항목의 `src: ""` 안에 파일 경로를 넣습니다.
3. `hint`는 참고용 예시 경로이므로, 실제 사용할 파일을 정하면 `src`에만 넣어도 됩니다.
4. 예시는 아래처럼 쓰면 됩니다.

```js
{
  id: "kids-ski",
  type: "video",
  title: "유아체육 · 스키 수업",
  src: "자료/유아체육강사/스키수업 동영상1.mp4",
  hint: "자료/유아체육강사/스키수업 동영상1.mp4"
}
```

이미지는 `type: "image"`, 동영상은 `type: "video"`로 두면 됩니다.

GitHub Pages에 올릴 때는 한글·공백 파일명도 동작할 수 있지만, URL 문제가 생기면 `assets/media/` 폴더를 만들고 `kids-ski-01.mp4`처럼 영문 소문자 파일명으로 바꾸는 것을 추천합니다.
